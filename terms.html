1. What Steven Is

Steven is a moderation bot for Emergency Response: Liberty County (ERLC) private servers. It connects to the ERLC API to monitor active players and automatically flag, kick, or ban players based on configurable rules — including account age, Roblox items worn, friend count, and zone violations. It also provides tools for staff to manage whitelists, submit global blacklist requests, look up players, and view server moderation history.
